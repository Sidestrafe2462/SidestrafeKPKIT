THIS IS, FOR THE MOST PART, AN EXACT CLONE OF THE MOST COMMONLY EDITED FILES IN MY GAMEDATA.


To install this THE COMPREHENSIVE AND EASILY UPDATED WAY:

    Move (DO NOT DELETE OR COPY) all of your folders (including Squad) out of your GameData to a safe location.

IMPORTANT - Your GameData must be fully empty for the installation to work.

    Download and install GitHub Desktop
    Click File --> Clone a repository then the URL tab
    Enter https://github.com/Sidestrafe2462/SidestrafeKPKIT
    Click Choose... and pick your empty GameData directory, DO NOT CLICK CLONE YET!

IMPORTANT - Before clicking Clone you MUST do Step 6:

    In Local Path, Delete /SidestrafeKPKIT from the end so that the directory actually terminates at GameData, and not GameData/SidestrafeKPKIT
    Now click Clone
    Move your Squad folders and any extra mods back into GameData.

IMPORTANT - Do not overwrite mod folders included in the repository.

Note: You absolutely can install personal mods or other mods with this repo active. There is a .gitignore file that will explicitly ignore files not intended as part of the main modpack, but it is non-exhaustive. If you see a diff log ("[x] changed files" in GitHub Desktop) this is not a concern and will not interfere with updates. Only if you are contributing to the pack do you need to make sure this is clear. If you are, you can get in contact or make a PR updating the .gitignore
Updating

To update this patch list

    1. Open GitHub Desktop
    2. Click "Fetch Origin" (This may not be needed, in which case go to step 3)
    3. Click "Pull Origin"

That will automatically update any files covered by this repo in your GameData to match my own latest upload.
