# KALvionics

Thank you for installing KALvionics!
This mod feeds live flight data from your craft into the KAL-1000 controller, driving its sequence position in real time.
NOTE - This mod REQUIRES the Breaking Ground DLC and Module Manager.
-------------
INSTALLATION
-------------
1. Install [ModuleManager](https://github.com/sarbian/ModuleManager)
2. Drop `GameData/KALvionics` into your KSP `GameData` folder
-------------
USAGE
-------------
To use, simply place a KAL-1000 controller and under the 'Avionics' dropdown select a control input. When using an avionics input, the play speed and direction of the KAL controller will be hidden.
Available inputs: Airspeed, Altitude (ASL), Altitude (AGL), Vertical Speed, Target Altitude
Airspeed ranges are editor-only. Altitude and vertical speed ranges have in-flight sliders and can be adjusted mid-flight.
-------------
AXIS BLENDING
-------------
Pitch, roll, and yaw stick inputs can be overlaid on top of the other input modes. Useful for quadcopters. Each rotor will need its own KAL controller and the relevant axis (pitch, roll or yaw) assigned to it, plus the collective control input such as Altitude (AGL).
